# 📌 Project Overview

Financial institutions process millions of transactions every day, making fraud detection one of the most critical business challenges.

This project develops an **Enterprise AI Fraud Detection System** capable of identifying fraudulent financial transactions using Machine Learning while providing business insights through an interactive dashboard.

The solution combines:

- Exploratory Data Analysis (EDA)
- Feature Engineering
- Machine Learning
- Model Evaluation
- Explainable AI
- Business Analytics
- Interactive Streamlit Deployment

---

# 🎯 Business Problem

Traditional rule-based fraud detection systems often:

- Produce a large number of false positives
- Fail to identify evolving fraud patterns
- Require extensive manual investigation

This project aims to:

- Detect fraudulent transactions accurately
- Reduce financial losses
- Improve operational efficiency
- Support real-time fraud investigation

---

# 📊 Dataset

The dataset contains mobile financial transaction records including:

- Transaction Type
- Transaction Amount
- Sender Balance
- Receiver Balance
- Transaction Step
- Fraud Label

Additional engineered features were created to improve predictive performance.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/Katariayash28/AI-Fraud-Detection-System.git
```

Go to the project directory

```bash
cd AI-Fraud-Detection-System
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```
